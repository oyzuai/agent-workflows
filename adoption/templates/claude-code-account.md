# Claude Code account instructions

For substantive work, use the shared agreements, maintainer profile, and Claude Code adapter in the stable local checkout of `agent-workflows`. If your installed Claude Code supports imports, use unquoted `@path` lines to import those files from this checkout; otherwise open them explicitly. See `providers/claude-code.md` for surface limitations and current official documentation.

Keep project-specific build, architecture, and verification requirements in that repository's own instructions. Personal filesystem skills do not thereby become account-synced or cloud skills.
